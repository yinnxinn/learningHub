## 核心论文追踪平台

### Hugging Face Papers（2025-2026 热点枢纽）

| 平台 | 地址 | 特点 |
|------|------|------|
| **HF Trending Papers** | https://huggingface.co/papers | 社区投票排序，每日更新，聚合 arXiv + GitHub Stars |
| **HF Daily Papers** | https://huggingface.co/papers?type=paper | 按时间线浏览 |
| **HF Papers of the Week** | https://huggingface.co/papers?filter=paper_of_the_week | 编辑精选 |

> 2025-2026 年 Hugging Face Papers 持续追踪多篇重磅论文，GitHub Stars 超 10k 的热门项目包括 MinerU（63k+⭐）、PaddleOCR-VL（77k+⭐）、SmolDocling（59k+⭐）、TradingAgents（75k+⭐）。

## 追踪策略建议

```

  → Hugging Face Trending Papers（浏览标题，收藏感兴趣篇目）
  → Artificial Analysis（快速了解模型性能格局变化）

深度阅读（每周）：
  → 筛选 2-3 篇重点论文精读
  → 优先阅读 GitHub Stars 5k+ 的实现

月度总结（每月）：
  → 梳理本月 SOTA 变化
  → 更新个人知识库/笔记系统
```

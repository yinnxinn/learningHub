## GitHub Trending 追踪技巧

### 推荐浏览方式

| 方式 | 地址 | 说明 |
|------|------|------|
| **全局每日趋势** | https://github.com/trending?since=daily |
| **Python 每日趋势** | https://github.com/trending?l=python&since=daily |
| **AI 话题页（最多星）** | https://github.com/topics/ai?sort=stars |
| **LLM 话题页** | https://github.com/topics/llm?sort=stars |
| **Agent 话题页** | https://github.com/topics/agents |

### 筛选技巧
- 在 Trending 页面用 `?l=python` 筛选特定语言
- 用 `?since=daily/weekly/monthly` 切换时间范围
- `tab=repositories` / `tab=developers` 切换仓库/开发者视图

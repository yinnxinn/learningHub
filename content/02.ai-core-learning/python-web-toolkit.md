## 常用工具包

- `fastapi`：现代 Python Web 框架
- `uvicorn`：ASGI 服务启动器
- `sqlalchemy`：数据库 ORM
- `pydantic`：数据校验与配置管理
- `httpx`：异步 HTTP 客户端
- `rich`：终端输出美化
- `typer`：命令行工具开发

## 入门建议

先用 `fastapi + pydantic + uvicorn` 做一个最小接口项目，再逐步接入数据库和测试。
